# Unique

Unique is an AI agent. Its purpose is to split a large task into subtasks and carry them out in isolation and in parallel.

The model decides how to split the work, or it follows a scheme the user prepared in advance.

Unique can create executors and tools from several kinds of models:

- text LLMs
- image generation
- music and sound generation
- video generation

All executors and tools share one workspace and communicate with each other.

Each LLM executor keeps its own context. Splitting the work into isolated subtasks expands the context of the whole project, so the work can continue at a higher quality for a long time.

The interface is localized for Russian, English, and Chinese.
